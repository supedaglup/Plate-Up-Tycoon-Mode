# Tycoon Mode: Marketing cards (3-star reward, Management Desk -> Marketing).
#
# How to edit:
#  - One line = one card:   Name | Price | Days | Effects | Flavour text
#  - Price: coins. Days: how many days the campaign runs (it ends at the start of the night it runs out).
#  - Effects: one or more "kind=value" separated by commas. Kinds:
#       customers   = more customers a day, in %            (customers=10 -> +10% customers)
#       rep_serve   = extra reputation for every serve      (rep_serve=0.5)
#       rep_daily   = reputation added every night          (rep_daily=10)
#       tips        = extra tip chance, in percentage points (tips=10 -> +10%)
#       price       = customers pay more for everything, in % (price=5)
#       patience    = extra seconds of patience in the queue (patience=15)
#       decay       = less reputation lost every night, in % (decay=20 -> 20% less)
#  - Lines starting with # are notes. Blank lines are ignored.
#  - At most 40 cards are used (the first 40). The desk offers 3 random ones each day; a restaurant runs at most 3.
#  - Save and rebuild the mod to use your changes. Cards already running keep their place in this list, so don't
#    reorder lines in the middle of a run (add new ones at the end).
