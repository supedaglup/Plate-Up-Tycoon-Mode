# Purchasing Desk menu layout.
#
# How to read / edit this file:
#   + Name [IconAppliance] {FallbackCategory}   a folder (a tile that opens a page). Indent = nesting (2 spaces).
#   ApplianceName                                 an appliance tile (KitchenLib ApplianceReferences name).
#   # ...                                         a comment.
#
# - [IconAppliance] is optional: the folder's tile shows that appliance's picture (else its first appliance).
# - <Recipe, Recipe...> is optional: the folder also gets every ingredient those recipes and all their Recipe Mastery
#   add-ons need (English recipe names), so an add-on's ingredients sit with their recipe. Anything already in the
#   folder or one of its sub-folders is not repeated. The menu log marks those as "(recipe)".
# - {FallbackCategory} only goes on top-level folders: purchasable appliances this file does not mention
#   are added to the end of the top-level folder whose fallback category the game's shop tags point to,
#   so nothing is ever missing. The menu log (TycoonMenuLayout.txt) marks those as "(auto)".
# - The same appliance may appear in several folders (e.g. Tomato is in every dish that uses it).
# - Appliances the game doesn't sell are skipped. A folder left with one appliance is dropped and that
#   appliance shown in the parent instead; an empty folder is dropped.
# - Inside a page: folders first (in this order), then appliances from cheapest to most expensive.
